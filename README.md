# projeto-aquario
Sistema de gerenciamento para aquários com foco em automação operacional. Oferece controle completo da fauna, exportação automatizada para Excel e emissão de fichas veterinárias, transformando dados brutos em ferramentas de decisão rápidas e organizadas

# Linguagens e Frameworks Utilizadas:
  - Python
  - Django
  - Bootstrap
  - JavaScript
  - Html / css
  - Sqlite3

# Como Instalar
- 1: python -m venv venv
- 2: Caso seja windows venv/Script/Activate | Caso seja linux source venv/bin/activate
- 3: pip install -r requirements.txt
- 4: cd djangoapp
- 5: python manage.py runserver
